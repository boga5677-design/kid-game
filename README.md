# 小小腦力樂園 iOS 15.8 + 英文學習整合版

Deployment Target：**iOS 15.0**，可在 iOS 15.8 / 15.8.x 執行。

## 原有腦力遊戲
- 找一找、找一樣、顏色圖形、迷宮、連連看、數一數、數學小高手、記憶挑戰
- 題目 0.5 秒後自動朗讀、重播按鈕、星星、成就
- 連連看保留拖曳與點兩張配對

## 已整合的英文部分
- 123 個生活主題單字 + 0–100 數字，共 224 個幼兒英文單字
- 13 個分類
- 美式 / 英式發音
- 20 關英文聽力闖關（每關 5 題）
- AI 發音跟讀：示範念完後 **等待 0.5 秒才開麥克風**，避免示範音被收音
- 發音辨識與相似度評分
- 每日 5 單字任務
- 寵物成長（使用目前三毛孩主視覺，不改用舊版花色錯誤的黑糖圖）
- 家長模式、英文成就
- 英文與腦力遊戲共用星星總數
