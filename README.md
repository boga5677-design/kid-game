# 小小腦力樂園 Android v0.5

這版以 `docs/approved-home-preview.png` 為首頁版型基準重做，先完成 Android；iOS 不在本版處理。

## 本次指定修正

- 刪除首頁「一起來挑戰吧！」大標題。
- 首頁改為：使用者資訊 → 每日任務 / 星星寶箱 → 偶貴 / 黑糖 / 熊熊 → 8 個遊戲按鈕。
- 三毛孩、遊戲圖示、桌面圖示直接取自這次核准的預覽素材，不再使用前版簡化角色。
- 所有遊戲卡標題與副標題都有 AutoSize，避免小螢幕文字爆框。
- Android 實體返回鍵 / 返回手勢改成「上一頁」：
  - 遊戲 → 首頁
  - 英文子功能 → 英文首頁 → 主首頁
  - 成就 → 主首頁
  - 只有在主首頁再按返回才離開 App。
- 8 個腦力遊戲保留：找一找、找一樣、顏色圖形、迷宮、連連看、數一數、數學小高手、記憶挑戰。
- 題目仍為進頁 0.5 秒後朗讀，並有重播按鈕。
- 連連看保留拖曳 + 點選兩種操作。
- 英文小教室整合在首頁主視覺區塊下方，不破壞核准預覽主要構圖。
- 英文資料共 224 個：123 個生活單字 + 0–100 數字。
- 英文功能：單字、美 / 英發音、聽力、測驗、發音跟讀。
- 發音跟讀：示範音播放結束後，再停 0.5 秒才啟動麥克風。

## v0.5.5 顏色圖形修正

- 題目不再固定為「藍色圓形」。
- 每題隨機從藍、紅、綠、黃、紫中選擇顏色。
- 每題隨機選擇「圓形」或「正方形」。
- 因此會出現「藍色正方形」等題目，藍色方格可正常作答。
- 正確答案一定完全對應題目的顏色與圖形。
- 每題固定有 3 個正確答案。
- 干擾選項不會再產生與正確答案外觀完全相同、卻被判錯的情況。
- 正確項目點過後會停用，避免重複計分。

## v0.5.6 顏色圖形題目輪替修正

v0.5.5 雖然已改成隨機顏色＋圖形，但仍可能剛好再次抽到「藍色圓形」，
因此看起來像題目沒有更新。

v0.5.6 改成固定輪替 10 種題目：
1. 紅色圓形
2. 綠色正方形
3. 黃色圓形
4. 紫色正方形
5. 藍色正方形
6. 紅色正方形
7. 綠色圓形
8. 黃色正方形
9. 紫色圓形
10. 藍色圓形

新版第一次進入「顏色圖形」會從「紅色圓形」開始，
所以可以直接確認 APK 是否真的更新成功。
