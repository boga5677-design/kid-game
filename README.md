# 小小腦力樂園 Android v0.5

這版以 `docs/approved-home-preview.png` 為首頁版型基準重做，先完成 Android；iOS 不在本版處理。

## 本次指定修正

- 刪除首頁「一起來挑戰吧！」大標題。
- 首頁改為：使用者資訊 → 每日任務 / 星星寶箱 → 偶貴 / 黑糖 / 熊熊 → 8 個遊戲按鈕。
- 三毛孩、遊戲圖示、桌面圖示直接取自這次核准的預覽素材，不再使用前版簡化角色。
- 所有遊戲卡標題與副標題都有 AutoSize，避免小螢幕文字爆框。
- Android 實體返回鍵 / 返回手勢改成「上一頁」：
  - 遊戲 → 首頁
  - 英文子功能 → 英文首頁 → 主首頁
  - 成就 → 主首頁
  - 只有在主首頁再按返回才離開 App。
- 8 個腦力遊戲保留：找一找、找一樣、顏色圖形、迷宮、連連看、數一數、數學小高手、記憶挑戰。
- 題目仍為進頁 0.5 秒後朗讀，並有重播按鈕。
- 連連看保留拖曳 + 點選兩種操作。
- 英文小教室整合在首頁主視覺區塊下方，不破壞核准預覽主要構圖。
- 英文資料共 224 個：123 個生活單字 + 0–100 數字。
- 英文功能：單字、美 / 英發音、聽力、測驗、發音跟讀。
- 發音跟讀：示範音播放結束後，再停 0.5 秒才啟動麥克風。

## v0.5.2 藏寶圖更新

- 首頁「每日任務」現在可點擊，進入冒險藏寶圖。
- 每日任務以 5 個島嶼檢查點呈現，日期變更後會自動重置為 0/5。
- 每完成一個遊戲／英文測驗／聽力挑戰，地圖前進一格。
- 首頁「星星寶箱」現在可點擊進入藏寶圖。
- 每累積 30 顆星可打開一次寶箱並取得徽章。
- 寶箱徽章會同步出現在「成就徽章」頁。
- Android 實體返回鍵／返回手勢會返回上一頁。
