# 小小腦力樂園 Android v0.5

這版以 `docs/approved-home-preview.png` 為首頁版型基準重做，先完成 Android；iOS 不在本版處理。

## 本次指定修正

- 刪除首頁「一起來挑戰吧！」大標題。
- 首頁改為：使用者資訊 → 每日任務 / 星星寶箱 → 偶貴 / 黑糖 / 熊熊 → 8 個遊戲按鈕。
- 三毛孩、遊戲圖示、桌面圖示直接取自這次核准的預覽素材，不再使用前版簡化角色。
- 所有遊戲卡標題與副標題都有 AutoSize，避免小螢幕文字爆框。
- Android 實體返回鍵 / 返回手勢改成「上一頁」：
  - 遊戲 → 首頁
  - 英文子功能 → 英文首頁 → 主首頁
  - 成就 → 主首頁
  - 只有在主首頁再按返回才離開 App。
- 8 個腦力遊戲保留：找一找、找一樣、顏色圖形、迷宮、連連看、數一數、數學小高手、記憶挑戰。
- 題目仍為進頁 0.5 秒後朗讀，並有重播按鈕。
- 連連看保留拖曳 + 點選兩種操作。
- 英文小教室整合在首頁主視覺區塊下方，不破壞核准預覽主要構圖。
- 英文資料共 224 個：123 個生活單字 + 0–100 數字。
- 英文功能：單字、美 / 英發音、聽力、測驗、發音跟讀。
- 發音跟讀：示範音播放結束後，再停 0.5 秒才啟動麥克風。

## v0.5.5 顏色圖形修正

- 題目不再固定為「藍色圓形」。

- 每題隨機選擇「圓形」或「正方形」。

## v0.6.3 遊戲卡朗讀修正

問題原因：v0.6.2 在點遊戲卡時先執行 `speakChinese(game.title)`，接著 `navigateTo()`；但切頁的 `renderScreen()` 與 `showGame()` 會執行 `tts.stop()`，所以「找一找／找一樣」語音剛開始就被取消。

修正方式：
- 點遊戲卡後先進入遊戲頁。
- 切頁完成後 0.1 秒再朗讀遊戲名稱。
- 題目仍在進入後約 0.5 秒自動朗讀。
- 自動題目朗讀使用 `QUEUE_ADD`，會排在遊戲名稱後面，不互相截斷。
- 主畫面仍不顯示獨立喇叭；只有遊戲頁的「🔊 重播題目」保留喇叭。
