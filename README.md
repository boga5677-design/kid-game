# 小小腦力樂園 Android v0.7.0

本版針對首頁預覽圖做「結構層級」修正，而不是再裁 PNG：

- 8 張遊戲卡：白色圓形底座 + 圖案，由同一個 Canvas View 繪製。
- 完全不再使用 game_*.png 作為首頁遊戲圖示，因此沒有方形底、白角、殘影的來源。
- 每日任務 / 星星寶箱：同樣改為單一 Canvas 圓形底座。
- 移除圖示容器本身的 elevation，避免 Samsung 裝置把圓形陰影畫成矩形。
- 保留遊戲卡「先朗讀名稱，再進入遊戲」功能。
- 保留 v0.6.7 其他英文、發音、藏寶圖與切字修正。
